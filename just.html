just.args module¶

Argument-parsers for argparse

class just.args.DateTimeArg(format_str)[source]¶

Bases: object

Type parser for datetime strings for argparse.ArgumentParser. Uses datetime.datetime.strptime to parse datetime-strings on the command-line using a format-string.

ex:

>>> arg_parser = argparse.ArgumentParser()
>>> arg_parser.add_argument("--date-time", type=DateTimeArg("%Y-%m-%d %H:%M:%S.%f"))
_StoreAction(...)
>>> arg_parser.parse_args(["--date-time", "2020-02-29 12:34:56.789"])
Namespace(date_time=datetime.datetime(2020, 2, 29, 12, 34, 56, 789000))

just.args.LogLevelArg(level_name)[source]¶

Translate a log-level name to its actual integer representation. Supports any log-level name in a case-insensitive fashion, including aliases (i.e. “debug” -> DEBUG, “warn” -> WARNING, “fatal” -> CRITICAL).

Can be used as the value for the type parameter of an argument in argparse.ArgumentParser, enabling parameters like --log-level FATAL. Will raise an argparse.ArgumentTypeError for unsupported values, so that argparse will show useful error-messages to the user on the command-line.

ex:

>>> arg_parser = argparse.ArgumentParser()
>>> arg_parser.add_argument("--log-level", type=LogLevelArg)
_StoreAction(...)
>>> arg_parser.parse_args(["--log-level", "DEBUG"])
Namespace(log_level=10)
Parameters:

level_name (str) – any supported log-level name from the logging module.

Raises:

argparse.ArgumentTypeError – for an unsupported value to argparse

Return type:

int

Returns:

the log-level int corresponding to the log-level name str.

just.deprecate module¶

Deprecation decorator

just.deprecate.deprecated(arg=None, since=None)[source]¶

Decorator to mark a function as deprecated. Emit DeprecationWarning when a decorated function is called.

The warning goes to stderr, so the examples below capture it with warnings.catch_warnings(record=True) rather than printing it.

ex:

>>> import warnings

without parentheses:

>>> @deprecated
... def deprecated_func_1():
...     return None
>>> with warnings.catch_warnings(record=True) as caught:
...     warnings.simplefilter("always")
...     deprecated_func_1()
>>> caught[0].category.__name__
'DeprecationWarning'
>>> str(caught[0].message)
'deprecated: deprecated_func_1'

with parentheses:

>>> @deprecated()
... def deprecated_func_2():
...     return None
>>> with warnings.catch_warnings(record=True) as caught:
...     warnings.simplefilter("always")
...     deprecated_func_2()
>>> str(caught[0].message)
'deprecated: deprecated_func_2'

with a version:

>>> @deprecated(since="0.3")
... def deprecated_func_3():
...     return None
>>> with warnings.catch_warnings(record=True) as caught:
...     warnings.simplefilter("always")
...     deprecated_func_3()
>>> str(caught[0].message)
'deprecated: deprecated_func_3 (since version: 0.3)'

Return the first item in iterable for which condition(item) is true. If no condition is provided, bool() is used, it check the truth-value of item. If no item is found to satisfy the condition, raise ValueError.

Parameters:

  • iterable (Iterable[T]) – an Iterable of items of type T

  • condition (Callable[[T], Any]) – returns whether the item is true.

  • default – when no item is found, don’t raise exception, return this value.

Return type:

Optional[T]

Returns:

the first item in iterable that is true.

Raises:

ValueError – when no item is found to satisfy the condition

no condition given:

>>> print(first([0, 0, 0], default=None))
None
>>> first([0, 0, 1, 0, 2, 0])
1
>>> first([None, 0, 1, False, True, [], {}])
1

condition given:

>>> print(first([1, 3, 8, 9], lambda x: x > 10, default=None))
None
>>> first([1, 2, 3, 8, 9], lambda x: int(x) % 3 == 2)
2
>>> first([None, 0, 1, [], {}], lambda x: x is not None)
0

class just.heap.Heap(data=None, key=None)[source]¶

Bases: object

Priority Heap class using the standard heapq module.

peek()[source]¶

Show the top of the heap.

Add item into the Heap.

pop()[source]¶

Remove from Heap item with highest priority.

pushpop(item)[source]¶

Push item on the Heap, then pop and return the smallest item from the Heap. The combined action runs more efficiently than heap.push() followed by a separate call to heap.pop().

replace(item)[source]¶

Pop and return the smallest item from the heap, and also push the new item. The heap size doesn’t change. If the heap is empty, IndexError is raised.

This one step operation is more efficient than a heap.pop() followed by heap.push() and can be more appropriate when using a fixed-size heap. The pop/push combination always returns an element from the heap and replaces it with item.

The value returned may be larger than the item added. If that isn’t desired, consider using heap.pushpop() instead. Its push/pop combination returns the smaller of the two values, leaving the larger value on the heap.

class just.heap2.KeyHeap[K: SupportsLessThan, T: SupportsLessThan](data, key)[source]¶

Bases: Generic[K, T]

A min-heap ordered by a key-function, the way key= orders sorted().

Internally stores (key(item), item) tuples so ordering follows the key, while the public API accepts and returns the original items of type T.

Note: if two items produce keys that compare equal, heapq falls back to comparing the items themselves, so T must be orderable in that case (or keys must be unique). This matches the classic (priority, item) idiom.

just.lock.lock_file(file_path)[source]¶

Lock-file context-manager. Defines a scope of code protected by a lock-file. The lock-file at the given path is created when entering the context, and deleted when exiting the context. The context can only be entered if the lock-file does not already exist.

ex:

with lock_file("/tmp/example.lock"):
    # ensure that only one process can call `access_something_sensitive()`
    access_something_sensitive()
Parameters:

file_path (str) – the path to the lock-file.

Raises:

LockFileExistsError – when the lock-file already exists

just.retry.retry(error, tries, delay=0.0)[source]¶

Retry decorator. Retries the function for tries when encountering Exception of type error. Other exceptions fall through. Wait for delay seconds between each try.

Parameters:

  • error (Type[Exception]) – the Type of Exception that wil cause a retry.

  • tries (int) – the number of tries.

  • delay (float) – the number of seconds to wait between tries (default 0.0).

ex:

>>> @retry(RuntimeError, tries=4, delay=0.1)
... def test_func() -> str:
...     return flaky_func()
...
>>> print(test_func())

class just.retry.RetryIterator(attempts)[source]¶

Bases: object

Retry iterator. Generate a RetryContext for a given number of attempts. Each try will be a RetryContext, which will call the RetryIterator.succeed on success to end iteration.

ex:

>>> for attempt in RetryIterator(attempts=3):
...     with attempt:  # RetryContext
...         flaky_func()
...
failed attempt 1
caught something - retrying 1 / 3 ...
failed attempt 2
caught something - retrying 2 / 3 ...
failed attempt 3
caught something - retrying 3 / 3 ...
succeed()[source]¶

Called by the generated RetryContext when a try is successful, ending iteration.
